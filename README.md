# 月圆之夜断网工具 操作手册 (v0.9.6)

## 1. 工具简介

本工具用于 Windows 系统下的网络管理，主要功能包括：

- 一键断网/恢复，支持**多个目标程序同时断网**或**全局断网**
- 独立音量控制（静音/恢复目标游戏音量）
- 退出时自动恢复音量（与网络恢复逻辑一致）
- 实时 Ping 监控（顶部时间栏显示延迟）
- 自动启动并监控目标游戏
- 内置 Markdown 文本查看器（字体、颜色可配置）
- 窗口置顶、透明悬浮、可拖动
- 单实例运行，防止多开

## 3. 配置文件说明 (config.json)

所有设置保存在 `config.json` 中，首次运行自动创建。修改后重启工具生效。

```json
{
  "block_time": 3,                          // 默认断网时间（秒）
  "window_width": 160,                      // 窗口逻辑宽度（会乘以DPI缩放）
  "window_height": 160,                     // 窗口逻辑高度
  "bg_color": "#E0E0E0",                   // 中央播放区背景颜色
  "drag_color": "#D0D0D0",                 // 顶部拖动条颜色
  "transparent_color": "#00FF00",          // 透明色（勿修改）
  "window_x": null,                        // 窗口X坐标（null自动居中）
  "window_y": null,                        // 窗口Y坐标
  "sound_volume_view_path": "",            // SoundVolumeView.exe路径（可留空）
  "volume_mute_value": 0,                  // 静音目标音量（0-100）
  "launch_app": "default",                 // 连带启动应用：default/空/手动路径
  "block_targets": ["default"],            // 断网目标列表，可多个；空列表表示全局断网
  "ping_target": "qq.com",                 // Ping目标地址（留空禁用Ping显示）
  "auto_exit_on_game_exit": true,          // 游戏退出后是否自动退出工具
  "md_font_family": "微软雅黑",            // Markdown 字体
  "md_font_size": 10,                      // Markdown 字号
  "md_font_color": "#000000",             // Markdown 字体颜色
  "md_bg_color": "#FFFFFF",               // Markdown 背景颜色
  "md_scroll_pos": 0.0,                    // Markdown窗口滚动位置
  "md_window_x": null,                     // MD窗口X坐标
  "md_window_y": null,                     // MD窗口Y坐标
  "md_window_width": 400,                  // MD窗口宽度
  "md_window_height": 300                  // MD窗口高度
}
```

### 3.1 路径特殊值

| 值 | 含义 |
|----|------|
| `"default"` | 使用同目录下的 `Night of the Full Moon.exe` |
| `""` (空) | 禁用（如 launch_app 不启动）或忽略该目标 |
| 其他字符串 | 手动指定的完整文件路径 |

### 3.2 断网目标列表 `block_targets`

- 可以设置多个目标程序，例如：
  ```json
  "block_targets": ["default", "D:\\Games\\Game2.exe", "C:\\App\\Game3.exe"]
  ```
- 列表中的每个有效路径都会被添加防火墙规则。
- 若列表为空 `[]`，则启用**全局断网**（禁用所有网卡）。
- 空字符串 `""` 在列表中会被忽略（不产生断网效果）。

## 4. 使用说明

### 4.1 启动

- 双击 exe，请求管理员权限（UAC弹窗），点击“是”继续。
- 窗口为透明悬浮样式，顶部显示时钟和 Ping 值。

### 4.2 界面布局

```
┌─────────────────────────────┐
│  小时:分钟:秒 - 025         │  ← 顶部时间栏，可拖动窗口
├─────────────────────────────┤
│ [⏱] [🔊] [🗑]              │  ← 设置时间、静音、清除规则
│                             │
│      (中央播放/停止区)       │  ← 点击切换断网
│                             │
├─────────────────────────────┤
│ [📋] [📄] [✕]              │  ← 日志、Markdown、退出
└─────────────────────────────┘
```

### 4.3 按钮功能

| 按钮/区域 | 功能 |
|-----------|------|
| 顶部时间栏 | 显示当前时间和 Ping 值，按住可拖动窗口 |
| ⏱ | 设置断网时间（秒），再次点击关闭并保存 |
| 🔊 | 静音目标游戏（需配置 SoundVolumeView 路径） |
| 🗑 | 强制恢复网络（删除防火墙规则+启用网卡） |
| 中央背景 | 点击开始断网，再次点击停止（提前恢复） |
| 📋 | 打开/关闭日志窗口 |
| 📄 | 打开内置的 `文本.md`（若存在） |
| ✕ | 退出工具 |

### 4.4 多目标断网

- 在 `config.json` 中设置 `block_targets` 为多个路径。
- 点击中央区域后，会为所有有效目标添加防火墙规则。
- 恢复时删除所有相关规则。

### 4.5 全局断网

- 当 `block_targets` 为空列表 `[]` 时，点击中央区域会禁用所有以太网/WLAN 网卡。
- 再次点击恢复网卡。

### 4.6 音量控制

- 点击 🔊 按钮，会将第一个有效目标程序音量调整为 `volume_mute_value` 设定的值（默认0）。
- 再次点击恢复原音量。
- **退出时自动恢复**：如果退出工具时仍处于静音状态，且目标程序仍在运行，工具会自动恢复原音量。

### 4.7 Ping 显示

- 顶部时间栏右侧显示 Ping 延迟（无单位）。
- 正常时显示数字（如 `25`）。
- 超时显示 `000`，连续超时递增（`001`,`002`...），最高 `999`。
- 恢复后重新显示正常延迟。

## 5. Markdown 查看器

- 点击 📄 按钮打开内置的 `文本.md`。
- 优先使用工具同目录下的 `文本.md`（外部文件），若不存在则使用打包内置的默认文件。
- 窗口位置、大小、滚动位置以及字体设置（字体、字号、颜色、背景色）会自动保存。

## 6. 打包方法

### 6.1 安装依赖
```bash
pip install pyinstaller
```

### 6.2 打包命令
```bash
pyinstaller --onefile --noconsole --icon=laptop-signal.ico --add-data "文本.md;." v0.9.6.pyw
```

- `--icon`：指定 exe 图标（ICO 格式）。
- `--add-data`：将 `文本.md` 打包进 exe，运行时通过 `sys._MEIPASS` 读取。
- 打包后 exe 位于 `dist` 文件夹。

## 7. 常见问题

### Q1：为什么快速双击 exe 会出现多个窗口？
- 已修复：程序会在提权前创建互斥体，防止多开。若仍出现，请重新打包最新版本。

### Q2：音量按钮不显示？
- 请检查 `sound_volume_view_path` 是否指向有效的 `SoundVolumeView.exe`。
- 且至少有一个有效的断网目标（`block_targets` 非空且路径存在）。

### Q3：全局断网后如何恢复？
- 点击中央区域停止断网，或点击 🗑 按钮强制恢复。
- 若工具异常退出，下次启动会自动恢复网络。

### Q4：如何设置多个目标程序断网？
- 在 `config.json` 中修改 `block_targets` 为多个路径列表。
- 例如：`["default", "D:\\Games\\Game2.exe"]`

### Q5：游戏退出后工具是否自动关闭？
- 可通过 `auto_exit_on_game_exit` 控制。
- 设为 `true`：所有目标退出后自动关闭工具。
- 设为 `false`：保持运行，等待手动退出。

### Q6：启动时出现“程序未找到”提示？
- 说明配置中某个路径无效。可以选择继续运行（功能受限）或退出修改配置。

### Q7：退出工具后音量没有恢复？
- 请确认您使用的是 v3.5.2 或更高版本。
- 如果目标程序在退出时已经关闭，则无法恢复音量（因为进程不存在）。

---

## 8. 注意事项

- 工具需要管理员权限，否则无法添加防火墙规则或禁用网卡。
- 请勿修改 `transparent_color`，否则窗口透明效果会失效。
- 全局断网会断开所有网络连接，请谨慎使用。
- 使用 SoundVolumeView 前请先运行一次以完成音频设备校准。
