## 简介
**月圆之夜断网工具** 是一款专为游戏《月圆之夜》设计的辅助工具，可在需要时临时断开游戏的网络连接，并在指定时间后自动恢复。工具采用完全透明的悬浮按钮面板，不遮挡游戏画面，支持一键断网、自定义断网时长、配置记忆等功能。所有操作均通过系统防火墙实现，无需安装第三方依赖，安全可靠。

## 功能列表
- ✅ 自动检测并启动《月圆之夜》游戏（如尚未运行）
- ✅ 一键断网，指定秒数后自动恢复网络
- ✅ 断网状态可视化（背景色变化 + 心跳波动画）
- ✅ 悬浮透明控件，置顶、可拖动，不干扰游戏
- ✅ 实时时钟显示（小时、分钟、秒）
- ✅ 断网时间自定义（1～3600 秒）
- ✅ 手动清除防火墙规则（立即恢复网络）
- ✅ 独立日志窗口，记录运行状态
- ✅ 配置文件自动保存窗口位置、断网时间、目标程序路径
- ✅ 点击秒数弹出气泡动画（可触发断网）
- ✅ 支持更改防火墙目标程序（连续点击齿轮按钮 15 次）

## 系统要求
- **操作系统**：Windows 10 / 11（64位）
- **管理员权限**：必须（用于操作 Windows 防火墙）
- **Python 环境**：无需安装（若使用打包好的 `exe` 版本）
- **目标游戏文件**：`Night of the Full Moon.exe`（或自定义程序）

## 快速开始
1. **将工具与游戏放在同一文件夹**  
   无论是 `exe` 版本还是 `pyw` 脚本，都必须与 `Night of the Full Moon.exe` 处于同一目录下（除非已通过设置更改目标路径）。
2. **以管理员身份运行**  
   双击工具图标，在弹出的“用户账户控制”窗口中点击“是”以授予防火墙修改权限。
3. **操作悬浮面板**  
   启动后屏幕中央会出现半透明悬浮按钮组，通过按钮即可完成所有操作。

## 界面说明
工具主界面是一个**完全透明**（通过色键抠图）的悬浮面板，包含以下控件：

| 位置 | 控件 | 图标 | 功能 |
|------|------|------|------|
| 顶部 | 拖动条 | `≡` | 显示当前时间（小时 ≡ 分钟），可拖拽移动整个面板 |
| 顶部左 | 时间按钮 | `⏱` | 设置断网秒数（1-3600） |
| 顶部中 | 设置按钮 | `⚙` | 连续点击15次可更改断网目标程序 |
| 顶部右 | 清除按钮 | `🗑` | 手动清除所有防火墙规则（恢复网络） |
| 中央 | 播放/停止区 | **背景矩形** + **心跳波动画** | 点击启动/停止断网；空闲时显示波动线条，断网时线条变为直线并背景变红 |
| 底部左 | 日志按钮 | `📋` | 打开独立日志窗口 |
| 底部中 | 秒数按钮 | `00` 动态数字 | 显示当前秒数，点击弹出秒数气泡（可触发断网） |
| 底部右 | 退出按钮 | `✕` | 退出工具，自动恢复网络 |

> 所有按钮均采用浅灰色背景（退出按钮为浅红色），深灰色文字，鼠标悬停时加深背景。

## 操作指南

### 断网控制
- **开始断网**：点击中央的浅灰色矩形区域（或任何弹出的气泡），背景立即变为红色，心跳线条变为水平直线，表示网络已断开。
- **停止断网**：在断网过程中再次点击矩形或气泡，立即恢复网络，背景恢复浅灰色，线条恢复波动。
- **自动恢复**：断网开始后，到达设定的秒数时会自动删除防火墙规则，网络恢复正常。

> 注意：若在断网过程中手动停止，网络会立即恢复。

### 设置断网时间
1. 点击 `⏱` 按钮，弹出小输入框。
2. 输入 1～3600 之间的整数（单位为秒），点击“确定”。
3. 设置立即生效，下次断网将使用新时长。

### 手动清除防火墙规则
点击 `🗑` 按钮即可立即删除所有由本工具创建的防火墙规则，恢复网络连接。适用于异常情况或手动恢复。

### 查看日志
1. 点击 `📋` 按钮，打开独立的日志窗口。
2. 日志窗口内显示工具的运行记录（命令执行、状态变化、错误信息）。
3. 点击“清空日志”可清除当前日志内容。
4. 关闭窗口（或再次点击 `📋` 隐藏窗口）不会清空日志。

### 退出工具
- **点击退出按钮** `✕`：自动保存配置、清除防火墙规则、关闭工具。
- **直接关闭窗口**：无法通过关闭按钮关闭（无边框窗口），只能通过退出按钮。
- **游戏退出时自动退出**：若目标游戏已关闭且当前未在断网，工具会在数秒内自动退出并恢复网络。

## 高级功能

### 更改目标程序
工具默认对 `Night of the Full Moon.exe` 进行断网，但支持更改为任意可执行文件：
1. 找到顶部中央的 `⚙` 齿轮按钮。
2. **连续快速点击 15 次**（1.5 秒内无点击会重置计数）。
3. 弹出“更改断网对象”提示后，选择新的 `.exe` 文件。
4. 点击“确定”，新路径会保存到配置文件中，**重启工具后生效**。

> 提示：更改后原游戏路径会被覆盖，如需恢复可删除 `config.json` 让工具重置为默认。

### 气泡动画
点击底部中央的秒数按钮（显示当前秒数），会从按钮上方冒出当前秒数的数字气泡，上浮至约两倍按钮高度后逐渐淡出消失。
- **动画特性**：同时最多存在 50 个气泡，点击间隔限制 0.3 秒。
- **交互**：点击任何气泡都可触发断网/恢复，与点击背景矩形功能相同。

### 配置文件
工具会在所在目录自动生成 `config.json` 文件，包含以下配置项：
```json
{
    "block_time": 3,
    "window_x": 100,
    "window_y": 200,
    "exe_path": "C:\\Games\\Night of the Full Moon.exe"
}
```
- `block_time`：断网秒数，可手动修改（1-3600）
- `window_x` / `window_y`：窗口上次关闭时的坐标
- `exe_path`：自定义目标程序路径（通过齿轮按钮设置）

## 常见问题与故障排除

| 问题 | 解决方法 |
|------|----------|
| 双击后无反应或闪退 | 确认已安装 Python 环境（若使用 `.pyw` 脚本）；或改用 `exe` 版本运行；确保以管理员身份运行。 |
| 提示“未找到目标程序” | 将工具与 `Night of the Full Moon.exe` 放在同一文件夹；或使用齿轮按钮手动指定正确的 exe 路径。 |
| 防火墙规则操作失败 | 确认已授权管理员权限；检查 Windows 防火墙服务是否运行（`Win+R` 输入 `services.msc`，找到 Windows Defender Firewall 设为自动并启动）。 |
| 窗口位置记忆出错（屏幕外） | 删除 `config.json` 文件，重新启动工具即恢复默认位置。 |
| 打包的 exe 被杀软误报 | 纯 Python 标准库打包可能被误判，添加信任或暂时禁用杀软。 |

## 技术细节
- **开发语言**：Python 3.8+，仅使用标准库（`tkinter`, `ctypes`, `subprocess` 等），零第三方依赖。
- **防火墙操作**：通过 `netsh advfirewall` 命令添加/删除出站和入站规则，规则名为 `Block_FullMoon_in` / `Block_FullMoon_out`。
- **DPI 自适应**：所有尺寸根据系统 DPI 动态缩放（基础 96 DPI 并额外放大 20%），确保不同分辨率显示一致。
- **进程监控**：后台线程每 3 秒检测一次目标程序是否运行，游戏退出时自动关闭本工具。
